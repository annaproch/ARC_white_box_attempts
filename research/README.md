# Research scripts

This is the early experiment index; its "shipped" descriptions below refer to
historical v3/v4 artifacts. For the current analytical estimator, Tucker/CP
experiments, learned corrections, and reproduction limits, see the
[project README](../README.md).

Experiments behind IMPROVEMENTS.md (all at the phase-1 shape: width 256,
depth 32, He init, no bias). Run from the `mlp_cumulant_propagation` repo so
its venv (torch + mlp_kprop) resolves:

```bash
cd ../mlp_cumulant_propagation && uv run python ../research/<script>.py
```

| script | question | verdict |
|---|---|---|
| `kprop_depth32.py` | kprop K=1/2/3(/augmented) accuracy + FLOPs at depth 32 | K≥3 over budget; K=2 ~2× better than starterkit cov baseline |
| `hybrid_test.py` | MC at the floor vs kprop K=2 vs per-neuron fusion | pure MC wins; fusion loses even with oracle weights |
| `qmc_test.py` | do better point sets beat iid MC? | Sobol+moment-matching 3.2× better |
| `scaling_test.py` | QMC convergence exponent β (floor vs full budget) | β≈0.83<1 → floor optimal |
| `fusion_test.py` | tuned fusion rules, 10 seeds | rejected; oracle only 1.37× |
| `k2aug_test.py` | K=2-augmented (11n³L) | unstable at depth 32; rejected |
| `gen_points.py` | generate shipped Sobol point set (v2) | — |
| `learn_weights.py` | ridge/BQ quadrature weights + spherical projection | weights collapse to uniform (<2%) |
| `optimize_points.py`(`_v2`) | SGD point optimization on the true ensemble | noise-level (+2%); Sobol+mm ≈ optimum |
| `calibration_ceiling.py` | how much K=2 error is ensemble-systematic? | 44% (20% is a global scalar) |
| `calibrated_k2.py` | end-to-end learned closure, first attempt | diverged (unbounded multiplicative corrections) |
| `calibrated_k2_v2.py` | stabilized (tanh-bounded, clipped, 4 MLPs/step) | **works: K=2 7.2e-5 → 2.4e-5 held-out (3×)** |
| `calibrated_k25.py` | "K=2.5": + diag-κ₃ tracking, Edgeworth terms, α-basis | see IMPROVEMENTS.md round 6 |
| `fused_v4_check.py` | honest fused-estimator check (independence, w fit, budget variants) | v4: −8.3% mini; over-floor beats point-cutting |

Shipped artifacts checked in here: `points_v3.npy` (the v3/v4 point set,
source of `whest-starterkit/points.npz`), `theta_k2_v2.npy` (the 192
calibration constants inlined in `estimator.py`).
